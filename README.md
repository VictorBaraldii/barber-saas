# Barber SaaS

Sistema SaaS para gestão e automação de barbearias desenvolvido com Java e Spring Boot.

## Tecnologias

- Java 21
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Docker
- React
- Maven

## Funcionalidades

- Cadastro de empresas
- Cadastro de usuários
- Cadastro de serviços
- Gestão de leads
- Autenticação JWT (em desenvolvimento)
- Dashboard (em desenvolvimento)

## Executando

```bash
mvn spring-boot:run
